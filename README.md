# 📖 Overview

**AI Debate Arena** is a full-stack AI-powered debate platform that enables users to practice structured debates against an intelligent AI opponent. The application leverages **Google Gemini AI** to generate context-aware counterarguments, evaluate user responses, and provide detailed performance analysis.

Users can participate in debates using **text or voice**, choose different difficulty levels, customize debate duration, and receive comprehensive feedback after every session. The platform securely stores debate history, provides analytics through an interactive dashboard, and supports authentication using both **Email/Password** and **Google OAuth**.

The project is built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)** with a responsive interface designed using **Tailwind CSS** and **Framer Motion**.
